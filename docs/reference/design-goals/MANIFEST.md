AI-drafted concept images promoted to reference artifacts because the owner adopted what they
show. A gauntlet critic judging a design round compares the built surface against the file
named here, by filename, never from memory. Draft text inside the images is model gibberish;
the LAYOUT and the listed decision are what is binding. `docs/DESIGN-GOALS.md` carries the
full decision list; this manifest maps decisions to files.

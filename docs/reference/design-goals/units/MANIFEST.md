course data in `apps/web/src/demo/pathwayMap.ts`, not from invented content: every node
label is a real lesson from that unit. These are the branching reference for the pathway
piece. Draft text is imperfect (unit 8 leaked prompt words into two labels); the LAYOUT,
the branch geometry, the per-node name labels and the motif icons are what bind.
